# Демонстрация за пять минут

1. Запустить программу, открыть http://localhost:5088. Объяснить цель: учёт запасов и сроков годности.
2. Показать продукт со вчерашней, сегодняшней датой и датой через неделю. Сегодня ещё годен; ближайшие три дня включены в soon.
3. Добавить и изменить продукт. Включить поиск, фильтр, сортировку заголовком, сменить число строк на странице.
4. Показать защиту удаления категории, связанной с продуктами.
5. Открыть «Заказы»: MOCK_DATA.json приходит Ajax-запросом; переключить Email, нажать заголовок Date, открыть форму. Archive не открывается.
6. Переключить источник на REST API. Добавить клиента и заказ, показать хранение на сервере. Отчёты работают с серверными заказами, а не с JSON-примерами.
7. Открыть Swagger; показать GET по ID и одну POST-операцию.
8. Запустить `dotnet test FoodShelf.sln -c Release` — 35 проверок. Для PostgreSQL выполнить `scripts/VerifyReports.ps1`.

## Частые вопросы

**Почему основная тема отличается от клиентов и заказов?** Основная тема — FoodShelf; индивидуальное задание описывает её. Для общих требований клиентов и заказов включён отдельный учебный модуль.

**Где PostgreSQL?** В основном режиме. Быстрое демо использует отдельный SQLite-файл, чтобы не требовать установки сервера. Для проверки процедур нужен PostgreSQL-режим.

**Зачем процедура и транзакция?** Процедура возвращает refcursor; его можно прочитать только в той же транзакции. После FETCH транзакция завершается.

**Как вычисляется средний чек?** Сумма выполненных заказов в часовом интервале, делённая на их количество. Часы без заказов имеют 0; представлены все 24 часа. Используется московское время.

**Почему нельзя редактировать Archive?** Это прямо предусмотрено frontend-заданием. Блокировка есть и в интерфейсе, и в серверном API.

**Что делает Nginx?** Принимает запрос браузера и передаёт ASP.NET Core. Нативный запуск проверен. В Compose он отдельный сервис.

**Где CI/CD?** В `.gitlab-ci.yml`: build, test, deploy. Установка сервера и регистрация Runner описаны в deploy/README.md. Показывать зелёный pipeline можно только после реального прогона; не выдавайте файл за выполненный запуск.

**Что осталось организационно?** GitHub опубликован: https://github.com/TortVkusite/FoodShelf . Остаётся согласовать тему, подтвердить запуск GitLab в рабочем Docker и получить подписи. Ссылки, оценки и отметки руководителя не выдуманы.
