# Соответствие присланным заданиям

Проверка от 12 ноября 2026 года. Тема FoodShelf новая; клиенты и заказы включены отдельным учебным модулем, чтобы не пропустить буквальные требования общего варианта.

| Требование | Реализация / состояние |
|---|---|
| .NET 8 или 9 | TargetFramework net9.0 у API и тестов |
| PostgreSQL, Entity Framework | Npgsql EF Core 9; фактическая проверка PostgreSQL 17.6 |
| Клиенты: имя, фамилия, дата рождения | Customers; дополнительно email и адрес для frontend-формы |
| Заказы: сумма, дата/время, статус, клиент | Orders; Pending/Cancelled/Completed, дополнительно Archive |
| CRUD и получение по ID для каждой сущности | Продукты, категории, места, клиенты, заказы |
| Фильтры по полям и страницы | ID, текстовые поля, диапазоны дат/чисел, статусы, ссылки; page/pageSize |
| Сумма выполненных заказов в день рождения | get_birthday_order_totals; проверенная контрольная сумма 350 |
| Средний чек по каждому часу | get_hourly_order_averages; 24 интервала и убывание среднего |
| Не менее 5 unit-тестов | 35 unit- и интеграционных проверок, все пройдены |
| Актуальный Angular, сборщик, CSS-препроцессор | Angular 22.2.6, Angular CLI, SCSS; сборка пройдена |
| Таблица как в frontend-примере | Latest Orders с нужными колонками, счётчиком и Actions |
| AJAX MOCK_DATA.json и loader | HttpClient; JSON-источник и индикатор запросов |
| Сортировка нажатием заголовка | Числа, строки, даты; проверено браузерным сценарием |
| Формы New Entry и редактирования | Все поля JSON; ID только для чтения, назначается автоматически |
| Archive некликабельный | Строка и карандаш не открывают форму; сервер тоже блокирует редактирование |
| Валидация и дополнительные колонки | Форматы, обязательность, длины, даты/суммы; Email/Address переключаются |
| Резиновая вёрстка от 1280×720 | Проверено 1280×720, 1440 и мобильная ширина 390 |
| Последние пять версий Firefox/Chrome/Opera/Yandex | Используется Angular browser baseline; проверены установленные Edge и Chrome. Историческая матрица пяти выпусков каждого браузера отдельно не подтверждена |
| Nginx | Конфигурация и фактический прокси-запуск на Windows, HTTP 200 |
| Docker Compose | app + db + nginx, многоэтапная сборка; config проверен, запуск движка недоступен |
| GitLab CE в контейнере | Compose подготовлен; фактическая установка требует работающего Docker |
| GitLab build/test/deploy | .gitlab-ci.yml и инструкция Runner готовы; удалённый прогон пока не выполнен |
| Публичный репозиторий GitHub | Опубликован: https://github.com/TortVkusite/FoodShelf |
| Отчёт, дневник, характеристика | DOCX по присланным образцам, визуально проверены; подтверждения руководителя не заполнены |

Реальная ссылка GitHub: https://github.com/TortVkusite/FoodShelf . До сдачи нужны снимки работающих GitLab CE/Runner/pipeline и подписи руководителя. Новую тему согласовать через индивидуальное задание. Готовность конфигурации и фактический запуск здесь разделены намеренно.
